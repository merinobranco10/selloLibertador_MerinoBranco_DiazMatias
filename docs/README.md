# Documentación

Informes semanales (hitos) del Módulo C, Bloque 3 de Sello Libertador. Cada hito se entrega como un único PDF por equipo.

| Hito | Archivo | Contenido | Estado |
|---|---|---|---|
| 1 | `Hito_1_Sello_Libertador.pdf` | Compilación, pruebas, guion manual, diseño y modelo de amenazas | Entregado |
| 2 | `Hito_2_Sello_Libertador.pdf` | Funcionalidad completa y ejecución del script de escenario | Entregado |
| 3 | `Hito_3_Sello_Libertador.pdf` | Seguridad, pruebas y gas | Pendiente |
| 4 | `Hito_4_Sello_Libertador.pdf` | Auditoría cruzada e integración final | Pendiente |

## Convención

- Nombre: `Hito_N_Sello_Libertador.pdf`, donde N es el número del hito.
- Cada versión nueva reemplaza al archivo del mismo hito.
